# RAG generation rules

Generate only the RAG slice selected by the task. Use PRD-derived familiar module names and the
selected framework conventions. Migrations own pgvector extension, tables, constraints, and indexes.
Durable ingestion uses the selected backend worker contract. Do not place provider keys or retrieval
logic in clients, silently mix embedding versions, ingest unsupported content, expose raw private
chunks, or accept model-created citations without deterministic validation.
